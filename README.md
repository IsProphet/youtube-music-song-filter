# YouTube Music Song Filter
A Firefox extension that automatically skips YouTube Music tracks when a title matches user-defined keywords.

## Features
- Automatic song skipping
- User-defined keyword list
- Enable/disable toggle
- Works directly on YouTube Music

## Installation
- Install via Firefox browser add-on store: https://addons.mozilla.org/en-US/firefox/addon/ytm-song-filter/

## Usage
Enter keywords, one per line:
live
slowed
remix
podcast

Songs that contain these keywords will be skipped automatically.

Toggle enabled checkbox and click save.
To disable, uncheck and click save.

This addon relies on YouTube Music's page structure, interface changes may break the extension requiring an update.

## Source

## Privacy Info
This extension stores user-defined keywords locally using Firefox's storage API.
No information is collected, transmitted, sold, or shared with third parties.
